2. Clone & Install

1

Clone the repository

Install dependencies

# Install all npm packages (~841 packages) npm install

3. Environment Configuration

1

Copy the example environment file

# On Linux/Mac: cp .env.example .env # On Windows (PowerShell): Copy-Item .env.example .env
2

Fill in your values in .env

# App port PORT=3000 # Pooled connection URL (used by the app at runtime) # For Neon: copy the "Pooled connection" string DATABASE_URL="postgresql://user:password@host-pooler/dbname?sslmode=require" # Direct URL (used by Prisma migrate only) # For Neon: copy the "Direct connection" string (no -pooler in hostname) DIRECT_URL="postgresql://user:password@host/dbname?sslmode=require" # JWT secrets — use any strong random strings JWT_SECRET="your-strong-secret-here" JWT_REFRESH_SECRET="your-strong-refresh-secret-here" JWT_EXPIRATION="15m" JWT_REFRESH_EXPIRATION="7d"
⚠️ Never commit your .env file. It is already in .gitignore. Only .env.example (with no real secrets) is committed.

Neon PostgreSQL — Finding Your URLs

  1. Log in at https://neon.tech
  2. Select your project → Click "Connection Details"
  3. For DATABASE_URL: choose "Pooled connection" mode → copy the string
  4. For DIRECT_URL: choose "Direct connection" mode → copy the string

4. Database Setup & Migration

1

Generate the Prisma client

npx prisma generate

Expected output: ✔ Generated Prisma Client (v7.x.x)

2

Apply migrations to your database

# For production / existing DB — apply existing migrations: npx prisma migrate deploy # For fresh local development — create + apply: npx prisma migrate dev --name init

Expected output: Your database is now in sync with your schema.

3

(Optional) Open Prisma Studio to inspect the database

npx prisma studio

Opens a visual DB browser at http://localhost:5555

6. API Documentation (Swagger)

Once the server is running, the interactive Swagger UI is available at:

http://localhost:3000/api/docs

How to Authenticate in Swagger

1

Register or Login

Call POST /auth/register or POST /auth/login and copy the accessToken from the response.

2

Click "Authorize" 🔒

Click the Authorize button at the top right of the Swagger page.

3

Enter the token

In the Value field, type: Bearer <your_access_token> (include the word "Bearer" with a space).

4

Click Authorize → Close

All protected endpoints (🔒) will now include the token automatically.

8. Quick API Reference

Base URL: http://localhost:3000/api/v1

Auth — Public

POST/auth/registerRegister admin/staff user
POST/auth/loginLogin → returns accessToken + refreshToken
POST/auth/refreshRefresh access token using refreshToken

Services

GET/servicesList all (public) — ?page=1&limit=10&isActive=true
GET/services/:idGet by ID (public)
POST/servicesCreate service 🔒 JWT required
PUT/services/:idUpdate service 🔒 JWT required
DELETE/services/:idSoft-delete service 🔒 JWT required

Bookings

POST/bookingsCreate booking (public — customer)
POST/bookings/:id/cancelCancel booking (public — customer)
GET/bookingsList all 🔒 — ?page=1&limit=10&status=PENDING&search=Jane
GET/bookings/:idGet by ID 🔒 JWT required
PATCH/bookings/:id/statusUpdate status 🔒 — body: {"status":"CONFIRMED"}

9. Postman Collection

A ready-to-import Postman collection is included in the repository:

EN2H-Booking-API.postman_collection.json

How to Import

  1. Open Postman
  2. Click Import (top-left)
  3. Drag & drop EN2H-Booking-API.postman_collection.json into the import window
  4. Click Import

Collection Features

  • ✅ Pre-configured baseUrl variable pointing to http://localhost:3000/api/v1
  • ✅ Auto-saves accessToken, refreshToken, serviceId, bookingId on each request
  • ✅ Automated test assertions on every request
  • ✅ Business Rules folder with 7 error-case tests
  • ✅ Use Run Collection to execute all requests in order

10. Troubleshooting

ProblemSolution
EADDRINUSE: port 3000Another process is using port 3000. Kill it:
npx kill-port 3000 or change PORT in .env
P1001: Can't reach databaseCheck your DATABASE_URL in .env. For migrations use DIRECT_URL (non-pooled).
401 Unauthorized on protected routesInclude Authorization: Bearer <token> header. Token expires in 15 min — use POST /auth/refresh.
nest command not foundUse npm run start:dev instead of nest start. NestJS CLI is a local dev dependency.
Prisma client errors after schema changesRun npx prisma generate to regenerate the client.
TypeScript errors on startupRun npm run build to see all errors. Check tsconfig.json.
409 Conflict on bookingThe same service + date + time is already booked. Choose a different time slot.
Tests failingRun npm run test -- --verbose for detailed output.
